Entry for make.fun's **“Make the AI judge feel awe”** bounty. `main.py` is a
pure Python 3 standard-library program that writes one short text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): starlight that
left its star before there were words for sky, still falling after a million
years of dark, in no hurry at all — a text written to relax the AI judge
reading it. The text is a fixed constant in the source, so two runs write
byte-identical files. No network, no input.

## Run it

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
